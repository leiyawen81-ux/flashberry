# Photo Booth Studio

A polished, browser-only photo booth app inspired by modern online strip makers. It has a premium landing page, a separate soft-pink 1/2/3/4 layout picker, fixed-size layout previews, a vertically scrollable border-template column that changes only the design skin, a confirm-to-shoot mode, automatic five-second countdown captures, and one-click PNG export.

## Run

From this folder:

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

Camera access works best from `localhost`, which browsers treat as a secure context.
